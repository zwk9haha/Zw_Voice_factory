# 斗破苍穹多角色工作流 Demo

入口：启动声色工厂后，刷新页面并进入工作流工作台，在“已有工作流”中选择 **demo · 斗破苍穹完整工作流（分步版）**。

工作流依次运行：导入 TXT → 文本分段与说话人识别 → 角色声线分配 → 批量语音生成 → RVC → 节目响度 → 合并音频；独立的推理设置节点提供路线、模型和语速。画布保留完整的节点、端口和拖线动画。

## 分步工作流

新版模板：`examples/workflows/doupo-split-workflow-demo.json`，名称为 **demo · 斗破苍穹完整工作流（分步版）**。

主线拆为：导入 TXT → 文本分段与说话人识别 → 角色声线分配 → 批量语音生成 → RVC 音色处理 → 节目响度 → 合并导出。另有独立的“推理模型与参数”节点，把生成路线和参数传给生成、RVC、合并节点；所有跨节点输入均有可见的数据连线。

已连接的输入、输出端口会填充主题色，节点边框也提示连接状态。删除最后一条对应连线后，端口恢复默认颜色。中文/英文显示与悬浮说明继续保留。

点击“角色声线分配”，可添加角色名并从五个极速声线中选择声音。点击“推理模型与参数”，可选择极速或质量路线；质量路线可选已有的七个推理模型，实际运行仍取决于本机模型资产是否就绪。质量路线必须为每个角色提供参考音频，不会自动跳过角色资产审核。

质量路线的 `reference_map` 以角色名为键，值可以包含 `reference_audio_url`、`reference_text`、`character_id`、`reference_id`、`voice_prompt`；复用声音库时同时提供 `catalog_asset_id` 和固定的 `catalog_version_id`。GPT-SoVITS V3/V4 需要与参考音频一致的参考文本。复杂参考信息和高级推理参数保留在折叠的 JSON 配置内。

RVC 默认关闭；开启后只使用现有批准流程准备好的角色模型，并继续遵循 RVC 的总开关。模型或总开关未就绪时保留基础音频，实际处理状态记录在节点输出。新批量节点的生成阶段不执行 RVC，由独立节点处理。原有复合多角色节点继续兼容，共用同一套批量生成实现。

批量生成节点可填写 `reuse_run_id`。仅复用已完成运行中同项目、同文本、同声线、同语速且音频文件仍存在的极速片段；应用过 RVC 或质量路线的片段会重新生成。复用数量记录在节点输出的 `reused_job_count`，每个片段记录 `cache_hit`。更改文本或声线、切换项目、删除音频文件均会重新生成受影响的片段。

## 节点操作

“导入文本”节点内的“选择 TXT 文件”会打开系统文件窗口，支持 UTF-8、UTF-8 BOM 和 GB18030。选择后的完整文本和文件名随草稿保存，重新载入时无需再次选择。替换已发布工作流的文件后，需要保存新草稿并发布再运行。

每个节点右上角的“中 / EN”切换输入、输出端口的显示名称。语言偏好随草稿保存；端口的英文标识和连线绑定不变。输入、输出两侧的全部端口均带有悬浮说明。

打开已保存的工作流，会恢复最近一次运行的状态。合并完成后，运行区显示音频播放器和下载入口。

## 运行详情

工作流编辑器顶部提供“编排画布 / 运行详情”切换。“运行详情”可选择同一工作流的历史运行，按实际开始时间检查节点的已解析输入、执行事件、实际输出和音频任务。未执行节点单独排在末尾，缓存命中、重试次数、失败原因和人工审核记录均按保存的数据展示。

选择分步版 Demo 的已完成运行 `15fb31a7b7784335`，进入“批量语音生成 → 音频任务”，可以搜索角色或台词，并选择任务读取其参数和音频。887 个任务按页展示；JSON 字段折叠展开，长文本可以展开全文或复制完整 JSON。任务详情可能反映后续响度、RVC 处理后的当前状态。

点击“定位画布节点”可以返回对应节点，画布草稿和连线会保留。项目页的“工作流 → 节点执行详情与输入输出”复用同一视图。旧记录缺失发布版本号时会明确说明；模型原始请求、提示词、Token 用量尚未采集。

## 画布布局

编辑器标题为“音声工作流”。顶部采用紧凑布局，底部“运行与输入”默认收起，为编排画布留出更多空间。

拖动能力节点栏和画布之间的竖向分隔条，可调整节点库宽度；拖动画布与节点配置栏之间的分隔条，可调整配置栏宽度。拖动底部横向分隔条，可调整运行面板高度，也可以用“展开 / 收起”按钮切换。面板尺寸会在当前浏览器自动记住。

双击分隔条恢复对应面板的默认尺寸，“重置布局”恢复所有面板。分隔条支持 Tab 聚焦和方向键微调，按住 Shift 可加大步长。窄屏下改为上下排列，运行面板仍可展开或收起。

本轮布局通过页面操作检查了三条分隔条、键盘微调、双击复位、刷新后尺寸恢复、画布与运行详情切换，以及 900 / 680 像素窗口宽度。1280×720 窗口下默认画布可视区域约为 854×497 像素；Demo 的 8 个节点位置与 13 条连线保持不变。

## 配音方式与限制

本 Demo 使用轻量 TTS 的五个预置声线，通过 `voice_map` 为角色指定声线；未启用 RVC，不依赖角色训练模型。不同角色可能共用同一预置声线。

角色识别使用角色名提示和说话归属规则，旁白与引号内对白分开；无法可靠确定说话人的对白标记为“未指定说话人”。该演示验证完整文件的多角色音频生成链路，不能代表小说所有对白已准确归属。

本 Demo 的角色分析配置为 `profile_mode: rules`：使用保守的规则画像，不调用云端。常规节点默认仍为 `configured`，使用当前配置的分析服务。

第一版云端运行（工作流 `workflow-6279fdbe3a814b67`、运行 `workflow-run-092954cc43b84bbc`）失败于画像阶段：P1 返回模型不可用，P2 返回上游 HTTP/2 流中断；该运行没有生成音频。后续规则画像版保留相同的完整文本和生成链路。
