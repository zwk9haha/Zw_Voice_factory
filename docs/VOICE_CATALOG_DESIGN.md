# 基础音色库设计

基础音色库不是简单的“女声/甜美”标签集合，而是角色审核模块的可复用声线基准。每个资产同时保存身份、声学属性、表达方式、使用场景和约束条件；生成的参考音频以版本形式保留，可以试听、切换、派生或删除。

## 首批覆盖范围

首批预置 24 个基础音色，覆盖：

- 女青年：清亮自然、甜美活泼、温柔轻盈、清冷克制、知性稳重、空气感柔和。
- 成年女性：温暖成熟、低沉冷静、明快利落、沙哑沧桑。
- 中老年女性：沉稳可信、慈和睿智。
- 男青年：清亮少年感、温和自然、爽朗活泼、低沉冷静、冷峻克制、热血有力。
- 成年男性：沉稳厚实、温暖成熟、磁性自然。
- 中老年男性：浑厚权威、粗粝沧桑、慈祥睿智。

这些资产是“搜索和试听起点”，不是对人物的最终判断。实际项目仍应结合角色文本、性格和导演文件进行复核。

## 参考文本

默认文本控制在约十秒，并保持所有基础音色一致，避免文本差异掩盖音色差异：

> 雨后的长街渐渐安静下来，我停在灯影交界处，听见远处的风，然后平静地说：今天的路，还要继续走下去。

页面另外提供疑问停连和轻情绪两条检查文本，用于观察疑问句、短停顿、气息连贯、句尾收束和动态变化。文本可以编辑，但横向比较时建议优先使用同一条文本。

## 质量优先参数

默认 `质量优先`：`CFG 2.4`、推理步数 `24`，目标时长约 `10` 秒。它不承诺对所有模型和硬件都是最优值，实际听感优先于参数名：

- 声线身份是否稳定，是否出现随机变年轻、变厚或变性别感。
- 字词是否清楚，停顿是否自然，句尾是否有吞音或拖尾。
- 是否存在明显爆音、削波、头尾静音过长和时长偏离。

另有 `稳定优先`（2.0 / 18）和 `音色探索`（2.8 / 30）。先用质量优先建立基准，再用探索方案派生同一音色的情绪版本；节目级响度统一应留到后续节目母带流程，不用于掩盖基础音色差异。

## 资产位置与生命周期

- 元数据：`outputs/voice_catalog/catalog.json`。
- 归档音频：`outputs/voice_catalog/audio/<asset_id>/<version_id>.wav`。
- 任务仍由启动器托管的单 GPU 音频队列执行，音色库只负责提交任务和接收状态事件。
- 生成完成后自动归档 WAV；历史版本默认保留，当前激活版本不能直接删除，需先切换到其他版本。
- 音色库不依赖小说项目，可以先建立通用库，后续角色匹配时再复制引用关系。

## 对外能力适配层

蓝图中的 Workbench、桌宠和其他前台不应直接依赖 `JobService`、VoxCPM2 或 GPT-SoVITS 的内部字段。Voice_factory 现在提供稳定的公开能力入口：

- `GET /api/capabilities/voice`：返回能力版本、可接受内容类型、产物类型和可编排节点目录。
- `GET /api/capabilities/voice/assets`：返回可被上层匹配的音色资产及当前激活版本状态。
- `POST /api/capabilities/voice/synthesize`：使用音色库版本或外部参考音频提交质量渲染任务，返回通用 `job_id`。

节点目录把当前已有链路抽象为文本接入、角色分析、参考音频、导演标注、质量渲染、极速渲染、RVC 稳定层和节目响度处理。后续 Workbench 只需要调度这些公开节点，不需要知道具体模型和文件布局；小说工作台仍然可以继续使用原有专用 API。
